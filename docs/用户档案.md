# 用户档案（DH.RustBase 定制部分）

> 通用偏好见用户级《跨项目接续协议》；本文件记录与 DH.RustBase 直接相关的用户口径。

## 业务口径

- **定位口径**：本库是「C# → Rust 渐进迁移」的地基，不是一次性重写——用户要求**双端共存**：C# 项目继续用 DH.NCore，Rust 项目用 dhrust，两侧**共用同一份配置**、语义一致，可同时运行互不干扰。
- **移植优先级**：以 DH.NCore 的实际行为为准（**排查优先读本地源码，不反编译**）；Rust 侧实现追求「行为等价 + 零多余依赖」。
- **依赖口径**：库要能被消费方轻量引入——重能力（网络/TLS/PTY/服务管理）一律 feature 门控，不被不需要的一方承担。
- **公共能力下沉口径**：多个消费方重复出现的实现（如 JWT→`Pek.RPermissions`、网络内核→`dhrust::net`）**下沉到公共库、勿逐仓复制**。
- **源码依赖拉新**：消费方编译报「缺少被引用的 API」时，按用户偏好**自动在本仓 `fetch` + `--ff-only` 快进后复测**，不等人为手工拉取、不重克隆。
