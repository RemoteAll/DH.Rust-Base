## 2026-10-20 · `panel_auth::TokenStore` 支持会话落盘与滑动续期

**用户原话**（Pek.RAgent 侧）：「RAent的登录是只要重启就要重新输入密码吗?这个能不能做成不要动不动的就被影响到要重新输入密码。因为这个不太可能直接用https的，那么多次输入很容易被截取」

**决策**：面板令牌表从「纯内存 + 固定 24h」升级为**可持久化 + 滑动续期**，但**只做加法、不改既有签名与默认行为**（`Pek.RAgent` / `Pek.RPanlServer` 等调用方无需改动即可继续用旧语义）。

**新增 API**（`src/net/panel_auth.rs`）：

- `ttl_ms()`、`clear()`、`revoke_all_except(keep)`；
- `touch(token) -> bool`：仍有效且剩余不足 `ttl/2` 时把到期时间重置为 `now + ttl`（返回是否改动，供调用方决定是否落盘；避免每个请求都写文件）；
- `snapshot() -> Vec<(token, expire, T)>` / `restore(items) -> usize`：导出未过期项与导入恢复（过期项忽略、容量上限 `MAX_TOKENS = 512`，超出丢最早到期）。

**边界**：库不引入 serde 依赖、不碰磁盘——序列化与文件位置由调用方决定（`Pek.RAgent` 用 `Data/panel-sessions.json`，原子写 + Unix 0600）。

**验证**：`cargo test --features net --lib panel_auth` 10 passed（新增 `token_store_snapshot_restore_and_touch` / `token_store_revoke_all_except`）。

## 2026-10-11 · 装备接续基建：补齐项目级入口三件套

**用户原话**：「DH.RustBase为什么没有用户级指令文档的，我明明记得是有让实现过，这是因为git给过滤掉没有提交到git吗？你直接帮我弄好」

**核查结论（先证伪）**：`git ls-files tools/continuity` 与 `origin/master...HEAD` 均显示 `tools/continuity/`（含 `templates/用户级指令.instructions.md`）、`install-global-instruction.ps1`、`sync-memory.ps1`、`commit-all.ps1`、`.vscode/tasks.json`（folderOpen 自检）、`docs/项目记忆.md` **已入库且已推送**；`.gitignore` 只过滤 `target` / `Cargo.lock` / C# 工具产物 / 压测产物，**没有过滤用户级指令**；本机已装副本 `%APPDATA%\Code\User\prompts\跨项目接续协议.instructions.md` 亦存在（v2026.10.10.4，脚本报「已是最新」）。

→ 真正缺的是**项目级入口三件套**：跨仓盘点（`G:\Code\Rust` 十个仓库）显示本仓是**唯一**缺少 `.github/copilot-instructions.md` + `docs/项目接续指南.md` + `docs/用户档案.md` 的已装备仓库（对比 Pek.RCode / Pek.RCard / Pek.RAgent / Pek.RPermissions / Pek.RPay / Pek.RRedis / Pek.RAdmin / Pek.RPanlServer 均已齐备）。没有这一层，打开本仓时没有「开工先读 → 用户级协议」的入口，观感即「没有用户级指令文档」。
