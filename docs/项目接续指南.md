> **开工先读（存在则读，按序）**：`.github/copilot-instructions.md` → 本文 → `docs/用户档案.md` → `docs/项目记忆.md` → `docs/决策记录.md` 最新节。

## 1. 项目是什么

Pek 生态的 **Rust 基础库**（crate `dhrust`，当前 **0.2.0**，edition 2021），对标 C# **DH.NCore**。目标不是把 C# 项目整体重写，而是**让两者共存**：同一份 `Config/` 配置文件、同一套定时与 Cron 语义、同构日志格式——C# 侧配置 C# 读、Rust 侧配置 Rust 也读，互不冲突。

**消费方（path 源码依赖，改动即影响）**：Pek.RCode、Pek.RCard、Pek.RAgent、Pek.RPanlServer、DHDeploy.Agent.Rust 等。远程 `https://github.com/RemoteAll/DH.Rust-Base.git`。

| `src/plugin` `src/patch` `src/zip` `src/term` `src/wecom` `src/staragent` | 插件包签名（Ed25519）、zstd 字典差分、极简 ZIP（store 法）、真 PTY 会话、企业微信机器人、StarAgent 配置注册 |

## 3. 常用命令

```powershell
cargo test --all-features                              # 全量单测 474 项（含 Cron/调度器/配置读写/日志/网络/Razor）
cargo clippy --all-targets --all-features
cargo check --no-default-features                      # 零特性（最小面）快速回归
powershell -NoProfile -File scripts\interop.ps1        # C#↔Rust：配置 13 字段 + Cron 求值 + 定时器（期望 === INTEROP PASSED ===）
powershell -NoProfile -File scripts\razor_interop.ps1  # Razor 子集双端渲染一致
# 跨仓提交/推送：
powershell -NoProfile -File tools\continuity\commit-all.ps1 -Message "feat: xxx"
```

## 4. 关键设计（改动前必读）

1. **feature 门控是库的骨架**：`secret` / `service` / `term` / `plugin` / `patch` / `razor` / `toml` / `zip-extract` 各自独立；`http-client` → `http-tls` → `net` → `net-tls` 逐层叠加。新增依赖必须 `optional = true`，重能力不得进默认编译面。
2. **与 DH.NCore 的等价是契约**：时间文本格式、配置字段与写回顺序（`serde_json` 开 `preserve_order`）、Cron `next/previous`、日志行 `HH:mm:ss.fff 线程ID 类型 名称 正文`（逐列对齐）——改这些先跑 `scripts/interop.ps1`。
3. **日志的既定权衡**：队列积压超 1024 条丢弃新日志（对齐 DH.NCore，防磁盘故障时内存无界）；备份清理空闲 5 秒检查目录、超量删最旧，候选文件满 1023 个时放弃本批写入。
4. **Razor 子集是「同一份模板双端渲染」**：`src/razor` 与 C# 侧渲染结果需一致（`scripts/razor_interop.ps1` 为门）；`Doc/Razor子集模板引擎架构.md` 是规范来源。
5. **网络层分层**：`http`（连接层）/`router`/`controller`（MVC 动作分发）/`static_files`（目录·嵌入·SPA 回退）/`ws`/`rpc`/`api_rpc`/`stun` 各司其职，语义层自研、连接层用 hyper/tokio。
6. **`tools/version-guard.ps1` 是共享件**：消费方打包脚本 `. (Join-Path ... 'tools\version-guard.ps1')` 后调 `Assert-VersionGuard`；改动需考虑所有消费方。

## 5. 坑与红线（已踩过）

- **本库是消费方的编译期上游**：删/改公共函数与结构体字段会直接打断 Pek.RCode / Pek.RCard / Pek.RAgent 构建——改完必须编译至少一个消费方复测。
- 中文 `.ps1` 必须 **UTF-8 with BOM**（PS 5.1 按 GBK 读无 BOM 会报语法错误）。
- `Cargo.lock` 不入库（见 `.gitignore`）；`tools/**/target/`、`tools/**/load-*.txt`（压测结果）也不入库。
- crates.io 直连不稳 → 一律走 `.cargo/config.toml` 的 rsproxy 镜像，勿临时改源。
- 只改某个 feature 时别用 `--all-features` 掩盖问题：至少补跑该 feature 的最小组合（如 `--features razor`）与 `--no-default-features`。
- 与 C# 互通类改动**必须实跑** `scripts/interop.ps1` / `scripts/razor_interop.ps1`，不能只靠单测。

## 6. 版本与发布

- 版本在 `Cargo.toml`（当前 **0.2.0**）；无独立打包流程，发行由消费方脚本拉起。
- 打包即升版本：消费方打包脚本调用 `tools/version-guard.ps1` 的 `-Bump`（补丁）/`-BumpMinor`；同版本内容变化默认拒绝（`-Force` 显式放行）。
